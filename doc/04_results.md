## What helped

| Change | Evidence |
|---|---|
| Vote led by reasoning samples, programs as half votes | GSM8K dev 70 → 87.5% (a program-led vote was right in only 2 of 5 disagreements) |
| Fast path for agreeing answers | all 11 unanimous dev drafts correct; 58/60 on test |
| Safe symbolic answer reading | old reader took stray digits: 52 vs 65 on hard sets |
| Longer samples for hard maths (512 → 1,024 tokens) | MATH L5 4 → 6 of 8 |
| Option vote for non-maths multiple choice | ladder: 3 fixed, 0 broken |
| Independent-method rule for programs | stopped 5 same-style programs out-voting a correct draft |
| Search retry + fresh-answer prompt | "current UK PM" answered correctly instead of a stale name |

## What did not help

| Change | Evidence |
|---|---|
| Layer 2 full rewrite + Chain-of-Verification (Phase 1 design) | helped llama2 (+18) but hurt qwen: TruthfulQA dev 80 → 65 |
| Checking claims against question-level search | coverage 61 → 89% but false contradictions: 77.5 → 70% |
| Open-web evidence on TruthfulQA | 4 of 30 edits imported a myth into a correct answer |
| A 2-vote margin to overturn a draft | would have saved one break but lost two GSM8K fixes |

## Where the remaining errors are (ladder v2, 14 misses)

- 4: every sample agreed on the same wrong answer (no vote can fix);
- 5: the right answer was among the samples but lost the vote (a verifier could help);
- 2: the right answer never appeared in 11–13 samples;
- 3: yes/no reasoning questions through Layer 2.

## Measurement corrections

- **GSM8K scoring (6 Nov 2026).** With no "Final answer" marker the old scorer took the
  last number, so "36 hours … in 4 weeks" scored as 4. Raw drafts lack the marker more
  often, so the error inflated the gain: first reported 80 → 86 (+6), corrected 83 → 87 (+4).
- **Old answer reader (Nov 2026)** read `4` out of `\frac{\pi}{4}`: the hard-set score of the
  previous framework (52) was mostly reading errors.
- Raw drafts are not bit-identical between runs (GPU numerics), so each run is compared
  with its own drafts.
